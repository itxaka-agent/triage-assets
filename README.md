# triage-assets

Public read-only host for screenshots and other artifacts referenced from PRs opened by [`kairos-triage-agent`](https://github.com/Itxaka/itxaka-agent) running as `@itxaka-agent`.

Layout: `<owner>/<n>/<name>.<ext>` (e.g. `kairos/4626/qemu-boot-shell.png`).

Files are referenced from PR comments via raw.githubusercontent.com URLs. Never contains secrets or credentials.
